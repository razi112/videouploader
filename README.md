# Simple Stream

Create a simple video website where only the admin can upload videos directly from a device, and everyone can watch the uploaded videos. Show videos on the homepage with thumbnails and titles. Use permanent video storage so videos remain available after refreshing the website. Keep the design clean, simple, and mobile-friendly. No YouTube links, no extra features, and no fake data. 😊
